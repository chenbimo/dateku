# 现状

这一页只描述现在是什么、不是什么，不承诺将来。

## 已有的

- 符合工作区规范的最小 MoonBit 模块骨架：`moon.mod`、`src/`、宽门禁与审计钩子
- 一个占位入口 `@dateku.hello()`，仅用于验证构建与发布链路
- 三端 target 声明为 `native`，随能力引入再决定是否放宽

## 没有的

- 没有日期解析、格式化、时区、加减等任何业务能力
- 没有发布到 mooncakes 的版本
- 没有 API 稳定性承诺：在这个阶段，任何接口都可能消失或改名

## 方向怎么定

不拍脑袋。等第一个真实使用场景出现（谁要在什么环境对日期做什么），从它反推出这套库的第一个公开函数。文档随后只有一处真相：能力进 `src/`，说明进对应页面，两处同步提交。
